Trying the current download

Apple has not notarized this download, so macOS may block it when you first open it.

If you choose to try the Mac app

Use a secondary Mac without sensitive data. Choose a local transcription model to keep audio on your Mac, and turn AI Enhancement off to avoid sending your transcript and other text for polishing. Set Settings > Rolling Buffer > Buffer Preload to Off to stop audio being sent before Shift if you use a cloud model.

Leave Screen Recording permission off. Granting it lets v1.95 capture a visible window when recording starts, even with Screen Context off. Roma also reads your clipboard when recording starts, even with Clipboard Context off. Do not grant Automation unless you need it. Quitting Roma stops microphone capture.

Do not disable Gatekeeper, the macOS security protection. If macOS blocks the app and you are not comfortable choosing Open Anyway, wait.

What Roma reads and sends

Microphone and cloud audio

With microphone permission, v1.95 listens while its rolling buffer is active. Its default buffer holds the latest three seconds of audio and replaces older audio as you speak.

With a cloud streaming model, v1.95 can start sending audio when its local speech detector fires, before you press Shift. The rolling buffer and audio that follows may reach that provider. Set Buffer Preload to Off before using a cloud model to stop this pre-Shift sending.

Local transcription and cloud text processing

A local transcription model keeps audio on your Mac. AI Enhancement can still send text to its provider, even with local transcription. Turn AI Enhancement off to avoid those text transfers. Cloud transcription sends audio directly to the provider you choose.

AI Enhancement sends your transcript, polishing instructions, custom vocabulary, and selected text Roma can read. With Clipboard Context on, it also sends clipboard text. With Screen Context on, it sends the app name, window title, and recognized window text. The provider's retention and training rules apply.

Clipboard and window collection

Roma reads your clipboard whenever you start a recording, even if Clipboard Context is off. With Screen Recording permission, it also captures and reads a visible window, even if Screen Context is off. It tries the frontmost window first, but v1.95 can fall back to another visible non-Roma window. Those switches only control what AI Enhancement receives. Revoke Screen Recording to stop window capture.

Saved history and API keys

Roma can save audio, transcripts, polished text, and the messages sent for polishing in local history on your Mac. Automatic cleanup is off by default. History cleanup can remove old records and their audio. Audio cleanup removes old audio but keeps the text record. Deleting local history cannot delete data a provider retained.

The public v1.95 download stores provider API keys in Roma's local settings, not macOS Keychain. Use a separate key you can revoke and set a provider spending limit when available.

Automatic connections

This website measures visits with Vercel Web Analytics. v1.95 checks beingpax.github.io for updates and announcements. The Mac app does not automatically send usage or crash reports to me, so I may not know about a problem unless you contact me.

Why Roma asks for broad access

Here is how v1.95 uses each permission.

Microphone
Required for dictation. Buffers and records speech.
Input Monitoring
Required for the global shortcut. Detects the keys you chose.
Accessibility
Works with Input Monitoring for shortcuts, inserts text, and can read selected or nearby text.
Screen Recording
Optional. Captures a visible window for on-device text recognition. v1.95 can fall back from the frontmost window to another visible non-Roma window.
Automation
Optional. Lets Roma paste through AppleScript and control supported browsers for Power Modes.

Revoke any permission in macOS System Settings. The related feature will stop working.
